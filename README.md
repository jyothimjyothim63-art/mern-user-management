# MERN User Management System

## Features
- User Registration
- User Login
- Dashboard (View Users)
- Edit User
- Delete User

## Technologies Used
- React
- Node.js
- Express
- MySQL

## How to Run

### Backend
cd backend
npm install
node server.js

### Frontend
cd frontend
npm install
npm start

## API Endpoints
- POST /register
- POST /login
- GET /users
- PUT /update/:id
- DELETE /delete/:id
